# Maintainers

The FLUX Simulation Engine is stewarded by its originating maintainers, the
same model the
[FLUX specification](https://github.com/Agenticstiger/flux/blob/main/GOVERNANCE.md)
uses. Decisions are made in the open, through issues and pull requests.

| Role | GitHub |
|---|---|
| Steward-maintainer | [@Speculator55005](https://github.com/Speculator55005) |

## Reaching a maintainer

- Bugs, questions and proposals: open an issue.
- Security problems and conduct reports: use GitHub's
  [private vulnerability reporting](https://github.com/Agenticstiger/flux-engine/security/advisories/new)
  on this repository, or contact the maintainer through their GitHub profile.
  Do not open a public issue.

## Becoming a maintainer

Sustained, good contributions (code, review, documentation, triage) over
several months, followed by a nomination and the consensus of the current
maintainers. The bar is judgment, not volume. A pull request that adds a
maintainer updates this file.

This file lists at least one reachable maintainer at all times.
