usage: fluxsim expr model [-h] --bundle BUNDLE [--simulation-id SIMULATION_ID]
                          [-j]

Print the attribute model an expression in this bundle is checked against.

examples:
  # every attribute in scope
  fluxsim expr model --bundle ./bundle

options:
  -h, --help            show this help message and exit
  --bundle BUNDLE       path to the FLUX bundle directory
  --simulation-id SIMULATION_ID
                        which Simulation document to resolve (default: the
                        bundle's only one)
  -j, --json            emit machine-readable JSON

docs: https://agenticstiger.github.io/flux/engine/reference/cli/expr.html
