usage: fluxsim gate decide [-h] --request REQUEST [-j]

Decide one request against one policy. Exit 0 allowed, 3 denied, 1 the request
could not be decided at all.

examples:
  # exit 0 allowed, 3 denied
  fluxsim gate decide --request request.json

options:
  -h, --help         show this help message and exit
  --request REQUEST  the request to decide, as JSON -- fields: policy
                     (object), request (object), skill (object) [optional]
  -j, --json         emit machine-readable JSON

docs: https://agenticstiger.github.io/flux/engine/reference/cli/gate.html
