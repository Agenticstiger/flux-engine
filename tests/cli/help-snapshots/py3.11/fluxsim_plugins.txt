usage: fluxsim plugins [-h] [-j]

List the vertical packs and the output sinks available in this environment,
with the extra each sink needs and whether it is installed. Nothing is
imported to find them.

examples:
  # list the vertical packs and the sinks
  fluxsim plugins

  # the same, as JSON
  fluxsim plugins --json

options:
  -h, --help  show this help message and exit
  -j, --json  emit machine-readable JSON

docs: https://agenticstiger.github.io/flux/engine/reference/cli/plugins.html
