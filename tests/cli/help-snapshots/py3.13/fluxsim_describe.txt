usage: fluxsim describe [-h] [--self] [-j]

Report this installation's identity, engine capabilities and full command
tree, so a consumer can render UI without lagging the CLI.

examples:
  # identity, capabilities and the command tree
  fluxsim describe --self --json

options:
  -h, --help  show this help message and exit
  --self      describe this installation (currently the only mode)
  -j, --json  emit machine-readable JSON

docs: https://agenticstiger.github.io/flux/engine/reference/cli/describe.html
