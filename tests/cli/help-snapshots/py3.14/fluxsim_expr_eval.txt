usage: fluxsim expr eval [-h] --bundle BUNDLE [--simulation-id SIMULATION_ID]
                         --values VALUES [-j]
                         source

Evaluate one expression against a subject view supplied as JSON.

examples:
  # check an expression and evaluate it against one subject
  fluxsim expr eval "tenureMonths > 12" --bundle ./bundle \
      --values '{"tenureMonths": 24}'

arguments:
  source                the expression source

options:
  -h, --help            show this help message and exit
  --bundle BUNDLE       path to the FLUX bundle directory
  --simulation-id SIMULATION_ID
                        which Simulation document to resolve (default: the
                        bundle's only one)
  --values VALUES       a subject view as JSON
  -j, --json            emit machine-readable JSON

docs: https://agenticstiger.github.io/flux/engine/reference/cli/expr.html
