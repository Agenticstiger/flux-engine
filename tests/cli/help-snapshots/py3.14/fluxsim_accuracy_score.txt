usage: fluxsim accuracy score [-h] --prediction-id PREDICTION_ID
                              --readout READOUT [--state-dir STATE_DIR] [-j]

Bind an ObservedReadout to a sealed prediction and record the verdict. A
prediction whose record no longer matches its seal is refused (FLX-7008).

examples:
  # score it once the outcome is known
  fluxsim accuracy score --prediction-id p-1 --readout readout.json

options:
  -h, --help            show this help message and exit
  --prediction-id PREDICTION_ID
                        the id the prediction was registered under
  --readout READOUT     an ObservedReadout as JSON -- fields: prediction_id
                        (string), metric_id (string), observed (decimal),
                        sample_size (integer), basis (live-ab|historical-
                        holdout|none), observed_at (string)
  --state-dir STATE_DIR
                        run-state directory (default: ./.flux)
  -j, --json            emit machine-readable JSON

docs: https://agenticstiger.github.io/flux/engine/reference/cli/accuracy.html
